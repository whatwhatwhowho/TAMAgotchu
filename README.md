# 🐾 TAMA Gotchu

A cute, retro Tamagotchi-inspired web companion built with HTML, CSS, and JavaScript. Designed with love to bring a smile to your face! ✨

## Features
- 🍞 **Feed Bread:** Restores health and keeps your companion happy.
- 💖 **Send Love:** Boosts affection with sweet interactive reactions.
- ⏰ **Dynamic Time States:** Companion poses and speech change automatically depending on the time of day.
- 📱 **Mobile Friendly:** Styled with an iPhone 13 aspect ratio for that authentic handheld device feel.
